The Diffing Algorithm: Using our food delivery app example, the diffing algorithm finds the difference between the old virtual DOM and the new virtual DOM and calculates the difference between the total no. of restaurants. This algorithm was known as reconciliation algorithm in react 16 and was known as react fiber in react 18
